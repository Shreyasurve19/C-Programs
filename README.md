A. SIMPLE CALCULATOR : 
The Simple Calculator project is a basic software application designed to perform arithmetic operations such as addition, substraction, multiplication and division.
It allows users to input two numbers and select an operation to compute result.
Also, this project helps beginners to understand various concepts like: variables and data types, user input, conditional statements(if/else), arithmetic operators, switch statements and error handling.

B. TRAFFIC LIGHT SIMULATOR : 
The Traffic Light Simulator is a simple project that mimics the behavior of real-world traffic lights.
It cycles through the standard light sequence—Red, Yellow, and Green using time delays.
This project helps in understanding basic programming concepts like conditionals, loops and timers.
It is commonly used for learning automation, simulation, and control systems in programming.
